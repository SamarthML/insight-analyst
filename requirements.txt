# Evaluation (Phase 4)
PyYAML                   # the eval question set
pandas                   # results tables
# ragas pulls in `langchain` and `langchain-openai`, which pin
# langchain-core<1.0.0 and will DOWNGRADE it, breaking langchain-chroma,
# -huggingface and -ollama (all of which need >=1.x). Install ragas first, or
# reinstall `langchain-core>=1.4.4` afterwards. ragas itself works fine on 1.x
# despite the pip warning. ragas also depends on the `openai` package, but no
# API key is needed unless you actually select an OpenAI model.
ragas

# Hosted judge for generation and RAGAS scoring. Groq is the default for every
# `--llm-provider` example in the README, so it is a hard requirement to
# reproduce the evaluation or generate a report; only retrieval runs without it.
langchain-groq
# The other hosted providers are optional and deliberately not installed here.
# Selecting one without its package raises a directed install message from
# `judges.get_llm` (see src/evaluation/judges.py) rather than a stack trace:
#     pip install langchain-anthropic     # --llm-provider anthropic
#     pip install langchain-openai        # --llm-provider openai (ragas pulls
#                                         # this in already, see note above)
